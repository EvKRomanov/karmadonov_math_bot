# Telegram-бот для продажи курса «Опора»

Бот для автоматизации продаж онлайн-курса «Опора» с интеграцией эквайринга ЮKassa через Telegram Payments (с формированием чеков по 54-ФЗ).

## Доступные тарифы
- **«Опора» с самопроверкой**: 4 900 ₽ / месяц
- **«Опора» с экспертной проверкой**: 5 900 ₽ / месяц

## Стек технологий
- Python 3.10+
- Aiogram 3.x
- YooKassa (Telegram Payments API)
- python-dotenv
