## Описание проекта
Программа представляет собой асинхронного Telegram-бота для онлайн-школы, автоматизирующего процесс презентации учебных программ, проверки знаний учащихся и приёма платежей. Бот интегрирован с официальным платёжным шлюзом ЮKassa (по 54-ФЗ), включает интерактивную викторину по теории чисел с подсчётом баллов и формирует именной электронный сертификат выпускника.

---

## Функциональные возможности

### Основной функционал
- 🎓 **Каталог курсов и предметов:** выбор тарифов по профильной математике («Опора» с самопроверкой и экспертной проверкой), физике и информатике.
- 💳 **Приём платежей (ЮKassa):** выставление счетов через Telegram Payments API, валидация заказов (`PreCheckoutQuery`) и обработка успешной оплаты с передачей данных для электронного чека (54-ФЗ).
- 🧠 **Интерактивная викторина:** тестирование по теории чисел с динамическим обновлением инлайн-кнопок и подсчётом результатов на базе FSM (Finite State Machine).
- 🏆 **Генерация сертификата:** сбор ФИО пользователя через машину состояний и формирование электронного сертификата об окончании обучения.

### Дополнительный функционал
- 📺 **Интерактивные видеоматериалы:** прямая интеграция со списком бесплатных вебинаров и открытых уроков на YouTube.
- 💬 **Модуль FAQ и поддержки:** раздел часто задаваемых вопросов и прямая ссылка для оперативной связи с руководством школы.
- 🛡️ **Безопасность:** вынос всех токенов и платёжных ключей в изолированные переменные окружения (`.env`).

## Требования к системе
- **Python:** 3.10 или выше
- **Операционная система:** Windows / macOS / Linux
- **Зависимости:**
  - `aiogram>=3.4.0` — асинхронный фреймворк для Telegram Bot API
  - `python-dotenv>=1.0.0` — загрузка переменных окружения из файла `.env`
  - `pydantic>=2.0.0` — валидация структур данных
  - `aiohttp>=3.9.0` — асинхронный HTTP-клиент
